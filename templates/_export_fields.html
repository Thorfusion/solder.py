{%macro export_settings(packbuild)%}
Export settings
The version of the build's selected modloader, such as Forge or NeoForge.
Build export delivery
The archive contains a small loader pointer; solder.py serves the build metadata and configuration.
The generated configuration and metadata are stored inside the exported archive.
SolderPy Loader follows this build, latest, or recommended through the bootstrap API. FileDirector, Modpack Director, and Packwiz use the selected hosted pointer. MCInstance Loader stores its configuration in the export, so it ignores this selector. Prism uses it when a downloader is selected.
Hybrid platform exports are snapshots; publishing a changed live build sends the next numbered patch. Solder API only with web-hosted SolderPy Loader synchronizes from the selected build channel automatically.
