Modrinth-CurseForge sync

Match the same downloader project on Modrinth and CurseForge so exported packs can install the native file from their target platform. Override Solder API only must also be enabled before a mapping can bypass a Solder API only export.

How CurseForge matching works

The mapping stores only the manually entered Modrinth and CurseForge project IDs. No CurseForge file metadata or matched file ID is saved. When exporting, solder.py resolves the exact Modrinth version selected in the build, asks CurseForge for compatible JARs, and tries these matches in order:

  1. the same SHA-1;
  2. the same filename and filesize; then
  3. the Modrinth version number in the CurseForge filename or display name.
CurseForge is not used for Technic launcher downloads. Technic continues to download the normal Solder packages from the Solder API and repository.
